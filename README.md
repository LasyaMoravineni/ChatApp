**ChitChat – A Real-Time Chat Application**

ChitChat is a web-based real-time chat application that allows users to engage in instant text-based conversations. It displays notifications for users joining/leaving and the current participant count, offering a smooth and responsive chat experience using WebSocket and Node.js.

🚀 **Features:**
Real-Time Chat: Users can send messages in real-time to all participants.
WebSocket Integration: Instant message delivery through bidirectional communication.
Join/Leave Notifications: Displays notifications whenever a user enters or exits the chatroom.
Participant Count: Tracks and displays the number of active users in the chat.


🛠 **Technologies Used**
HTML/CSS: Structures and styles the web interface for an intuitive and visually appealing experience.
Vanilla JavaScript: Adds dynamic client-side functionality for real-time messaging.
Node.js: Manages server-side logic and handles multiple concurrent connections.
Express: Simplifies server creation and routing.
WebSocket: Provides a persistent connection for real-time communication.
GitHub: Used for version control and collaborative development.


📦 **Installation and Running the Project Locally**
Follow the steps below to run the ChitChat application on your local machine:

1. Clone the Repository
   > git clone https://github.com/LasyaMoravineni/ChatApp.git
2. Navigate to the Project Directory
   > cd ChatApp
3. Install Dependencies: Ensure Node.js is installed on your system. Then, install the necessary Node.js modules
   > npm install
4. Run the Application
   Start the server by running the following command:
   > node app.js
5. Open the Application
   Once the server is running, open your browser and navigate to:
   > http://localhost:4000
You should now be able to use the ChitChat application for real-time messaging!

🌟 Usage
Joining the Chat: Enter your username and click the "Join" button to enter the chatroom.
Sending Messages: Type messages and press "Send" or hit the "Enter" key to send.
Participant Count: The app displays the total number of participants in real-time.
Exit Notifications: Users leaving the chat are indicated by a message in the chat window.
